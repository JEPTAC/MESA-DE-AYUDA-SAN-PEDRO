# Changelog · Reconstrucción visual

- Cambio definitivo de identidad a **Mesa de Ayuda TIC**.
- Logo institucional suministrado incorporado como marca principal.
- Eliminadas las múltiples hojas CSS versionadas de la entrega final.
- Eliminados los scripts visuales acumulativos de la entrega final.
- Consolidación en una única hoja `app.css` y un único `app.bundle.js`.
- Tipografía global redimensionada para evitar textos microscópicos.
- Sistema de iconos SVG para servicios y navegación.
- Nuevo sidebar, header, cards, botones y superficies.
- Nuevo tratamiento de Inicio, Mis solicitudes, Conocimiento y Estado.
- Calendario ampliado con mayor jerarquía, contraste y codificación semántica de eventos.
- Mejor responsive y dock inferior móvil.
- Se conserva la funcionalidad pre-Supabase construida previamente.
