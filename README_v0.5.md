# MESA 360 v0.5

Prototipo frontend avanzado de gestión de servicios institucionales para Alcaldía.

## Cómo probar
Abra `index.html` en un navegador moderno. No necesita servidor ni base de datos.

## Datos
La demostración usa arreglos JavaScript y localStorage. No contiene Supabase en esta fase.

## Perfiles de demostración
- Funcionario: autoservicio, radicación, solicitudes, conocimiento, estado y agenda.
- Gestor: suma Centro de Operaciones, continuidad ITSM, equipo, activos, catálogo e indicadores.
- Administrador: suma workflows y configuración.

## Archivos principales
- `index.html`: shell y vistas.
- `styles.css`: diseño base hasta v0.4.
- `app.js`: lógica base hasta v0.4.
- `v05.css`: capa visual v0.5.
- `v05.js`: capacidades nuevas v0.5.
- `ARQUITECTURA_PRE_SUPABASE.md`: modelo propuesto para la última fase.
- `BENCHMARK_MERCADO_ESTADO.md`: patrones de referencia.
