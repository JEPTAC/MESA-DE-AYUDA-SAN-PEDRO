# Mesa de Ayuda TIC · v0.7 UX / NAV / DESIGN SYSTEM

Esta versión eleva la experiencia de navegación y la capa visual del producto:
- mayor claridad visual;
- tarjetas y botones más notorios;
- diseño más llamativo y vivo;
- navegación más inmersiva;
- animaciones fluidas y ligeras;
- mejor lectura en pantallas pequeñas, medianas y portátiles.

## Cómo probar
1. Abrir `index.html` o servir la carpeta con un servidor estático.
2. Cambiar entre vistas Funcionario / Gestor / Administrador.
3. Recorrer Inicio, Agenda, Operaciones, Catálogo, Admin Studio y el asistente de radicación.
4. Verificar responsive en anchos de 640, 780, 980 y portátil.

## Capas agregadas
- `v07.css`: design system visual, responsive y motion.
- `v07.js`: microinteracciones, revelado progresivo y elementos decorativos.
