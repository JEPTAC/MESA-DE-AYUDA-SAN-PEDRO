# Mesa de Ayuda TIC · v1.0 UX Operations

Esta versión consolida la experiencia funcional pre-Supabase y separa claramente el portal del funcionario del workspace de operación.

## Funcionario
- Portal de autoservicio visual.
- Radicación guiada por pop-ups.
- Mis solicitudes, respuestas y trazabilidad.
- Centro de conocimiento contextual.
- Agenda y disponibilidad.
- Estado de servicios.
- Tendencias y respuestas frecuentes.

## Gestor TIC / Comunicaciones
- Centro de mando TIC.
- Inbox personal con colas inteligentes.
- Vistas Lista, Tablero, Agenda, Timeline y Carga.
- Selección múltiple y acciones masivas.
- Acciones rápidas sin abrir el caso.
- Pestañas de trabajo para múltiples solicitudes.
- Workspace del ticket en tres paneles.
- Timeline pública/interna.
- SLA visual y contexto relacionado.
- Copiloto operativo simulado.

## Calendario 3.0
- Mini calendario mensual.
- Día / 3 días / Semana / Recursos.
- Heatmap de ocupación semanal.
- Zoom, desplazamiento y bloques libres.
- Filtros por servicio, equipo y duración.
- Reserva directa.
- Drag & drop para gestores según la lógica ya existente.

## Backend
Supabase continúa fuera de esta versión. Toda la experiencia está modelada para conectar Auth, PostgreSQL, RLS, Storage, Realtime y Edge Functions en la fase final.
